## 励志奖学金/

存放 25 级国家励志奖学金和省政府励志奖学金的个人申请材料、汇总表，以及 23 级汇总表参考文件。

| 名称 | 说明 |
| --- | --- |
| [25励志.zip](励志奖学金/25励志.zip) | 25 级励志奖学金材料的打包备份（约 4.3 MB）。 |
| [25级国励志/](励志奖学金/25级国励志/) | 国家励志奖学金材料。含 15 名学生子文件夹，以及汇总表 `国家励志奖学金(带数据)-25级-.xlsx`。 |
| [25级省励志/](励志奖学金/25级省励志/) | 省政府励志奖学金材料。含 2 名学生子文件夹（徐天宇、高丹阳），以及汇总表 `省政府励志奖学金(带数据)-25级.xlsx`。 |
| [国家励志奖学金(带数据)-23级20251015修改.xlsx](<励志奖学金/国家励志奖学金(带数据)-23级20251015修改.xlsx>) | 23 级国家励志奖学金汇总表，主要作为 25 级填表时的字段和格式参照。 |

每个学生子文件夹内通常包含两类材料：

- **Excel 版**：个人奖学金信息表，文件名类似 `国家励志奖学金(excel版).xls`、`国家励志奖学金-赵博林.xlsx` 或 `省政府励志奖学金导入模板（Excel版）.xlsx`。
- **Word 版**：个人申请表，文件名类似 `国家励志申请表（word版）.docx`、`2025-2026学年国家励志奖学金申请表-赵博林.docx` 或 `省政府励志奖学金参考（Word版）.docx`。

不同学生交来的文件名不完全统一，但内容都是“个人申请表 + 信息表”两类。

## tmp/：表格处理脚本和检查产物

该目录是整理学年鉴定表和奖学金材料时留下的工作目录，不是正式提交材料。里面的脚本大多把根目录写死为 `D:\系统文件夹\Desktop\12`，移动整个文件夹后需要改路径才能运行。

### 根目录脚本

| 文件 | 说明 |
| --- | --- |
| [build_form.py](tmp/build_form.py) | 用 python-docx 从零生成学生学年鉴定表。 |
| [update_form.py](tmp/update_form.py) | 在已有鉴定表上填写或更新内容。 |
| [render_word.ps1](tmp/render_word.ps1) | 调用本机 Word 将 DOCX 渲染为 PDF/PNG，用于检查排版。 |
| [audit_read.ps1](tmp/audit_read.ps1) | 读取励志奖学金汇总 Excel 的数据，供后续比对使用。 |
| [audit_compare.ps1](tmp/audit_compare.ps1) | 将学生 Word 申请表与 Excel 汇总表逐字段比对，输出差异清单。 |
| [format_audit.ps1](tmp/format_audit.ps1) | 对比 23 级和 25 级励志奖学金汇总表的格式、列宽、合并单元格等。 |

### 子文件夹

| 目录 | 说明 |
| --- | --- |
| [gx/](tmp/gx/) | 早期核对脚本：读取个人 Excel/Word、导出字段、逐人比对、检查汇总表格式。 |
| [gxf/](tmp/gxf/) | 后期回填脚本：以个人 Word 申请表为准，把内容回填到 25 级 42 列汇总表，并做三方核对和抽查。 |
| [qa/](tmp/qa/) | 排版检查产物：学年鉴定表各版本的预览 PDF，以及 `source`、`updated`、`final`、`verified` 等截图。 |

如果不再修改鉴定表或奖学金表，`tmp/` 整体可以删除；需要保留可复现过程时再保留。

## 备注

- `.DS_Store` 是 macOS 生成的目录索引文件，可忽略或删除。
- 正式材料以根目录 DOCX、各奖学金文件夹中的汇总表，以及 `1/` 中的 DOCX/PDF 为准；`tmp/` 仅作过程留档。
- 策略报告的 Markdown 版本由 DOCX 自动转写，若需改动正文，建议先改 `1/策略报告.docx`，再重新导出 PDF 和 Markdown。
